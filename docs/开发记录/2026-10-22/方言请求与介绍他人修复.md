# 方言请求不触发与“介绍某人”被拒修复（2026-10-22）

## 现象（10:50–10:52 实测，毒舌风格会话）

| 用户 | 小安妮 | 问题 |
| --- | --- | --- |
| 小安妮，介绍一下张海超。 | 我还不认识张海超，画面里也没有这个名字，所以没法介绍。 | 把“介绍某人”当成认面前的人 |
| 陕西话介绍一下张海超。 | 我还不认识张海超，画面里也没这个人，没法用陕西话给你介绍。 | 同上，且未切陕西话 |
| 陕西话介绍一下自己。（网页文字） | 额是安妮……心里头护短得很。 | 文字带“额”，声音仍是普通话 |

## 证据与根因

- `var/logs/runtime-20261022-104734.log` 10:52:03：模型调用 `select_reply_style` 被判 `valid=False`；其余几轮没有方言工具调用。
- 方言：`explicit_language_request` 只认“用/说/讲/改成/换成/切换到 + 方言名”，方言名放句首的“陕西话介绍一下…”匹配不上；模型自行调用 `select_reply_style` 时，按工具说明不能拿地名“陕西话”当方言证据，参数被拒，TTS 保持普通话。
- 介绍某人：10-21 为防止“用旧记忆叫错人”加入 `IDENTITY_RULES`（认人只看画面）和“让你介绍某人时先 look_closely”，模型把“介绍一下张海超”也归为认人问题。另：长期记忆“用户名叫海超”按 10-21 决定不作为机器人级记忆注入，所以小安妮本就不知道张海超是谁。
- “你知道谁写的吗？”一轮 ASR 草稿为“你就说谁写的了吗”，语义本身含糊，未改。

## 修复

- `annie_runtime.language.explicit_language_request`：新增“方言名 +（来/给我/跟我…）+ 介绍/说/讲/聊/回答/念/唱…”句式；含“怎么/咋/什么意思/叫什么/叫啥”的询问不算请求。
- `ReplyLanguageState.reply_intent` 与 `RealtimeRobot._language_tool`：本轮用户已点名要求的方言调用 `select_reply_style` 时不再要求推断证据。
- `IDENTITY_RULES`：限定为“面前的人是谁、怎么称呼”；问某个名字的人时按记忆或常识回答，不知道就直说并可追问，不拿画面里有没有 TA 作答。视觉规则与 `look_closely` 描述改为“介绍面前某人”才看画面。认面前的人仍只看画面，不用记忆或自称名字称呼。

## 放宽语种/方言请求（同日，用户要求“都放宽松一点”）

- 名称表覆盖 TTS 能说的全部 20 种语言与 4 种方言，并收常用别名：俄语/俄文、意大利语、葡萄牙语、阿拉伯语、泰语、越南语、印尼语、马来语、菲律宾语、印地语、土耳其语、乌克兰语、韩国话/朝鲜语、日本话、汉语/国语、川话/成都话/重庆话、郑州话、西安话/关中话、广州话/香港话等。“白话”不收（“说白话”=说直白点）。`ms/fil` 同步加入语言策略与偏好白名单。
- 句式：“用/说/讲/唱/改用/换成/切到/切成…+（正宗的）+（量词）+语种”，“来+量词+语种”（来段粤语），“语种+（给我/跟我…）+介绍/回答/讲个/来一段/说说…”（俄语来一段、四川话给我讲讲），英文 “tell/sing/explain… in Russian”。
- 仍不算请求：否定（不要/别说/不想）、能力提问（你会说俄语吗）、翻译与“怎么说/叫什么”、普通谈论（原来英语这么难、你英语说得真好、聊聊英语学习、我在读英语专业、英语来自拉丁语吗）。“能不能/要不要用粤语说”不再被“不能/不要”误判为否定。
- 印地语、土耳其语、乌克兰语不在 TTS 官方 `language_hints` 列表，文字会切换，读音未验证。

## 会话一直用某种语言（同日 11:21 “俄语交互”会话）

- 现象：输入“希望这个会话一直用俄语的语言一直交互”，回“Хорошо, будем общаться на русском!”，之后说中文仍回中文。日志该轮无任何工具调用，库里无偏好。
- 原因：①保存全靠模型调用 `set_language_preference`，它只口头答应；②即使保存，模型的 `select_reply_style` 推断（intent）优先于保存设置；③提示只写代码 `ru`，且保留“整句外语必须跟随/这一轮整句是外语时仍用该语言回答”，与保存设置冲突。真实模型对照：仅写 `ru` 时中文输入全部回中文。
- 修改：
  - 运行时识别到“这个会话/本会话/这个对话…+一直/都用X”（scope=chat）或“以后/一直用X”（scope=robot）就自己写入偏好；“取消这个会话的俄语设置”“恢复默认语言”“清除机器人的语言设置”自己清除。单句“这句换成普通话”只影响本轮。
  - 有保存设置时，模型的语种推断不再覆盖它（情绪保留）；本轮明确要求仍优先。
  - 语言提示写明语种名并要求“全程用俄语回答，用户说中文也用俄语”，有保存设置时去掉“跟随外语”句；人格核心改为“明确要求和保存的语言设置优先，没有语言设置时整句外语必须跟随”。
- 真实模型（两种性格，保存俄语后连续中文输入 4 轮）：全部俄语回答；“这句换成普通话说：你好”回“你好。”。
- 工作台“回复语言”控件（头部“当前性格”旁，替换原只读“语言偏好”标签）：范围选“本会话/本机器人”，语言选“自动跟随”（=不保存偏好，跟用户说的语言走）或普通话/四川话/河南话/陕西话/粤语及 TTS 支持的 19 种外语；选定写 `PUT /api/robots/{id}/language-preference`，选“自动跟随”写 `DELETE`。本会话未设而机器人已设时显示“沿用机器人（X）”。悬停提示两级当前值与优先级（本会话优先于本机器人）。局域网 HTTP 无 `crypto.randomUUID`，请求 ID 回退 `getRandomValues`。头部工具栏允许换行、标签不折字。
  - 浏览器实测（隔离实例 127.0.0.1:18790，临时根目录与库，Room/视觉/本地模型地址指向本机空端口，未连真实设备；结束后已停止并删除临时目录与其运行日志）：1440 宽下本会话选俄语 → 库内 chat=ru；切本机器人选粤语 → robot=yue/cantonese；切回本会话显示俄语；本会话选自动跟随 → `DELETE` 200、chat 清空、显示“沿用机器人（粤语）”；390 宽无横向溢出。隔离实例无实时模型，`target` 不反映偏好，真实实例保存后会立即载入对话。
