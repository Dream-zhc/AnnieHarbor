Phase 4B｜独立 TTS、PCM 与嘴型

总状态：待人工验收；禁止将模型合成成功、Room 发布或浏览器试听当作设备已播。嘴型未安装/未运行时保持 not_connected。

1. 正式工作台

打开 React 工作台 →

选择当前机器人与 Room，查看 Realtime/TTS/嘴型状态、首音频和首发布时延。原始事件按机器人、Chat、Persona、generation 单独核对。

2. 安全前置

未完成设备停止/回执、麦克风 AEC 证据时，默认禁用发布。确认设备音量安全、无同 Room 第二麦克风音源、真实停止能力后，在本机 .env 显式设置 ANNIE_TTS_ENABLED=1 并按原启动器重启。不要将密钥贴到页面。

3. 真实音频

  1. A/roomv2 提交文字或说话 → 记录生成文本、TTS 首 PCM、reb_tts 已发布帧/样本，确认设备是否真正起播；缺回执写 unknown。
  2. B/roomv3 独立测试并让 A、B 同时输出；核对没有串房间、没有二次合成、没有双音轨。
  3. 生成中及设备播放中取消 A → 记录本地取消、stop 发布和设备确认停播三个不同时间点；B 不受影响。
  4. 断 TTS/Room、切 Chat/Persona、对齐超时与迟到事件，确认异常可见、旧 generation 不继续发布；检查独立 TTS 音色未变化。
  5. 安装并验证 ForcedAligner 后，同一份 reb_tts PCM + 对应文本生成嘴型；实测采样位置与播放时钟，算法失败不伪造音节边界。

以上均需操作和设备证据，不由 Fake 测试替代。未配置对齐依赖/AEC/设备回执时，本阶段只能作 TTS 协议/模拟 Room 的开发验证。
