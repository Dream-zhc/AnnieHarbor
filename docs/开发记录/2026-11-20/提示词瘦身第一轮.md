# 提示词瘦身第一轮（2026-11-20）

## 方法

往期真实对话均匀取样（每轮带前 3 轮上下文），每种提示词让真实 Qwen Realtime（文字模式）重新回答，由 qwen3.8-max 按 `scripts/对话质量评测.py` 的五项（接得住/像真人/不机械/连贯/分寸，1–5 分）打分；每删一组再做针对性检查——只看评分会漏掉功能退化。脚本与结果在 `var/tmp/20261120-prompt-ab/`（后续轮次还要用）。

## 采用的去重

- 【陪伴核心】去掉“历史用于理解指代而不是续答旧任务……换题或被打断就接住新内容”（已在【以当前这句为准】）和“先直接处理请求，简单回答简短”（已在【语音输出】）；保留“最新明确更正优先”“复杂问题完整解释，不为简短省略重点”。
- 【聊得有意思】去掉“换了话题就只答新话题”（同上），保留不重复、不总结不回顾。
- 【以当前这句为准】去掉“不要把你说过的话原样再说一遍”（【聊得有意思】已有）。
- 人格部分 2,511 → 2,455 字。测试：test_phase5 改为断言历史规则只在【以当前这句为准】里出现一次。
