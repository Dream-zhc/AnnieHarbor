## 修复

- **回声兜底（不依赖回声消除）**：扬声器正在播、或最后一条播放回执在 1.5 秒内时，识别出的文字如果是她正在说/刚说完的话（整句包含在内，或至少 4 个字且六成以上字对相同，覆盖“考一/烤鸭”这类识别错字），就当回声：
  - 识别中间结果阶段不确认打断，继续播；
  - 最终文字不建新一轮、不回复、不进旁听，已暂停的播放恢复；记 `self_echo` 日志并发 `transcript.ignored`（reason `self_echo`）。
  - 以“小安妮”开头的话是叫她，不算回声。
  - 用 10-20、10-21 全部 83 句真实用户原话（都假设上一句还在播）检查：判为回声的正好是演示里那 3 句，其余 0 误判。“北京有什么景点故宫颐和园”这种问题夹回声的整句仍当用户的话。
- **回声消除日志**：`cloud_aec status=...` 在状态变化时记一行（最多 2 秒一行），带 processed/bypassed/missing_reference/receipts/drops/errors 和回执延迟，下次能看出是哪种失效。
- **认人**：
  - 新增始终存在的【认人】规则（有没有画面都加）：只能通过画面认出人；看不到画面或画面没写名字时不知道面前是谁，不能用记忆或以前对话里的名字称呼，不能说“你是X”，对方自己说了最多说“你说你叫X”。
  - 名字类记忆不再是机器人级事实：键名以 `user_name` / `name` / `nickname` 开头，或文字是“用户名叫/用户的名字是/用户姓名/用户自称/用户叫做…”的，不提取、已存的不进会话记忆（数据库行保留）。“用户的猫叫咪咪”“用户叫车去机场”不受影响。
- **大屏同步**（`reb_display`，见 [数据大屏数据同步说明](../../规范/数据大屏数据同步说明.md) 第 4 节）：
  - 休眠/唤醒：已有 `wake.state`（SLEEP/WAKE_WAIT/ACTIVE/FOLLOWUP）。
  - `playback.state`：playing / held / stopped / drained，带来源（实体扬声器或网页试听），只发变化、只留最新。
  - `speech.ignored`：听到没回的话和原因（不是对她说的、实时模型判环境音、她自己的回声、实时模型判不完整、休眠时听到），原话最多 80 字。
  - `decision`：对话对象判断（结果、qwen-flash 的 robot/other、置信度、耗时、原话、一句 `summary`）和自发表情判断（选的表情、置信度、是否采用）。
- **qwen-flash 置信度**：先让模型在 JSON 里自报置信度，实测 154 次全是 0.95，没有信息量，撤掉；改为请求 `logprobs`，取“robot/other”两个词的概率（实测 0.56～1.0）。提示词保持原样，产品代码重放：日志原话该回的 53/56、闲聊误回 6/32，验证集 24/24、2/26，与之前一致。
