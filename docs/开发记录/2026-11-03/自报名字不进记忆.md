# 自报的名字、让她忘掉某人的话不进记忆（2026-11-03）

用户反馈：17:22 新会话开场她直接叫用户“大聪明张三”，用户问“这个张三是谁，没有记忆”。（文中真名一律写成张三。）

```text
本次问题与范围：17:00 用户说过一句带名字的话，记忆抽取把它记成了公共长期记忆“用户说自己是张三。”（key 形如 fact_person_<拼音>_name）。原有的名字拦截只认“用户的名字是 / 用户名叫 / 用户自称”和以 name 开头的 key，这种写法漏过去了，于是下一个来跟她说话的人都被当成张三。
目标与用户可见效果：自报的名字不再进记忆；已经存进去的同类旧记忆在召回时直接跳过（不删数据库）。名字只认摄像头人脸库。
输入 → 处理 → 输出：记忆抽取结果 → prepare_extracted_fact / is_meta_memory → 入库或丢弃；开场和检索召回 → is_meta_memory → 跳过。
改动文件：packages/annie-brain/src/annie_brain/memory.py、tests/test_demo_issues_1021.py。
保留项：“用户说自己是老师”这类职业、身份事实照常记；“用户的猫叫咪咪”“用户叫车去机场”“用户自己叫了外卖”照常记。
不做事项：不删数据库里的旧行；用户 17:41 已在记忆面板删过一批长期记忆，现存的长期记忆里没有再需要跳过的名字。
结果：相关测试和全量测试通过（只剩既有的 4 个失败）；重启主脑生效。
```

## 1. 拦截规则

| 写法 | 例子 | 处理 |
| --- | --- | --- |
| 说/称/表示/介绍 + 自己叫/名叫 | 用户说自己叫张三。 | 不记 |
| key 里有 name / nickname / called 一段，正文是“用户（说）自己是/叫” | fact_person_zhangsan_name：用户说自己是张三。 | 不记 |
| 只有“是”，key 也不是名字 | user_occupation：用户说自己是老师。 | 照常记（“是”也可能是职业） |
| 让她忘掉某人 | 用户要求当前助手忘记张三。 | 不记：记下来反而把要忘的名字留住了 |
| 让她退下 / 闭嘴 / 休眠 | 用户当前要求助手退下。 | 不记：一次性的休眠命令，留着会让她下次开场还记仇 |
| 空结果 | 无 | 不记：抽取模型的“没有可记的”被当成了一条记忆 |

抽取提示里同时加了一句：用户自报的名字（“我叫X”“我是X”）、让助手忘掉某人或退下的话都不提取：来的人很多，名字只认摄像头的人脸库。

## 2. 顺带看到的

- 今天的会话记忆里已有 5 条属于上表后三类（忘记某人、退下 4 条，空结果 1 条），重启后在召回时跳过。
- 右侧“今天的真实经历”里的“XX来了”是人脸识别的到达记录，17:22 她叫的名字不在其中；今天的经历默认不进提示词，只在她调用“回忆今天”工具时给她看。
- 删记忆清不掉心情和会话历史：重启后会话会带上这个会话最近 8 轮（日志 `history_turns=8`），所以 17:44 她还说“刚才不是让我闭嘴吗”。要干净开场就新建会话。
