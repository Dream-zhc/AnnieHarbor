# 动作立即触发：`offset_ms = -1`

> 2026-10-28。给嵌入式对接。**不新增字段**（用户确认）：`reb_main` 的 `action_trigger` 沿用 `data.offset_ms`，`-1` 表示**立即触发、不等音频**；`0`（及其它非负值）照旧锚定这一轮（同 `conversation_id`）的语音。起因：问“你看看左边有什么”时要先转头，做完（`action.finished`）主脑才取画面、才让她回答，这时还没有语音，转头必须立即执行。见[视觉意图协议](视觉意图协议.md)。

## 字段

| `data.offset_ms` | 含义 |
| --- | --- |
| `-1` | **立即触发**：收到就执行，不等语音、不等 PCM |
| `0` | 跟随这一轮语音：锚定同一 `conversation_id` 的语音开播（现有行为） |

其余字段和回执都不变：`script_id`、`conversation_id`、`anchor_source`；执行后照旧回 `action.started` / `action.finished` / `action.dropped`，`data` 带 `conversation_id + script_id`。

```json
{"type": "action_trigger", "ts": 1793000000000,
 "data": {"script_id": "look_left", "offset_ms": -1,
          "conversation_id": "5b0e8c1d9f2a4e7b8c6d3a1f0e9b7c2d",
          "anchor_source": "robot_main_brain"}}
```

## 主脑哪些发 `-1`、哪些发 `0`

| 动作来源 | 例子 | `offset_ms` | 原因 |
| --- | --- | --- | --- |
| 视觉意图的看向动作 | “你看看左边有什么”→`look_left` | `-1` | 先转头，等 `action.finished` 后再取画面回答，此时还没有语音 |
| 倾听动作 | 用户开口约 0.7 秒后 `listen_tilt` | `-1` | 用户还在说，本轮没有语音 |
| 说话时配的动作 | 每句话的点头、歪头 | `-1` | 主脑已按扬声器播放进度算好时机才发 |
| 说完后的内心反应 | `shy_retract` | `-1` | 语音已播完 |
| 点名动作、模型调用的动作 | “点个头”“摇摇头”“做个动作” | `0` | 随回复开口；主脑在本轮第一帧 PCM 发出后才发 |
| 表情 | 惊讶、坏笑等（带锚词） | `0` | 回复里出现目标词并且第一帧 PCM 已发出后才发 |

后四类以前都发 `0`，倾听和说完后的反应在嵌入式按 `0` 等语音时可能等不到（那一轮没有或已播完语音）；现在统一由主脑掐好时机、发 `-1` 立即执行。

## 待确认

- `look_left` / `look_right` / `look_up` 回 `action.finished` 时，头是否停在那个方向（不自动回正）。主脑在 `action.finished` 之后取画面；如果做完就回正，需要另给“转到位”的回执。
- 新动作和正在执行的动作（例如用户说话时的倾听动作）撞上时嵌入式怎么处理：打断旧的、排队，还是丢弃新的（丢弃请回 `action.dropped` 和原因）。
