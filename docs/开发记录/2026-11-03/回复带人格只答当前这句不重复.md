# 回复带人格、只答当前这句、不重复（2026-11-03）

用户要求（上一会话定下直接改的三件）：视觉回答要带当前人格的口吻；模型常接旧话题，要以用户当前这句为准；她会把说过的话原样再说一遍。

```text
本次问题与范围：视觉回答照念描述，换哪个人格都一样；外部事件（雷达靠近、空闲续聊、内心活动、提醒）的提示让她“顺着正在进行的话题”，把话题拉回旧事；11-02 18:56 识别终稿前被压住的回复，把她上一句招呼原样又说了一遍。
目标与用户可见效果：看图回答的事实照描述，说法是当前人格的；话题跟着用户这一句走；不再原样重复自己刚说过的话（用户说“再说一遍”“刚才说什么”除外）。
输入 → 处理 → 输出：会话指令末尾加【以当前这句为准】；外部事件提示只回应这件事，并附上她最近说过的话；识别终稿放行压住的回复时，多条只放最新一条，和最近说过的话一字不差就撤回、重新生成。
改动文件：apps/runtime/src/annie_runtime/realtime.py、apps/runtime/src/annie_runtime/idle.py、packages/annie-brain/src/annie_brain/event_policy.py、packages/annie-brain/src/annie_brain/inner_life.py、tests/test_reply_focus_1103.py（新）、tests/test_phase8_events.py。
保留项：人格核心与组合指令（test_dialogue_behavior 断言的部分不动）；唤醒/追问准入与放行时机；补答 _answer_recovered_call 流程；存库的 external_prompt 仍是原提示。
不做事项：改模型参数；识别终稿之后才开始的回复（边生成边播）不做重复检查。
结果：新增 5 个测试通过；全量 1334 通过，6 个失败与本次无关（见文末）；重启主脑生效；真机待验。
```

## 1. 视觉回答带人格

| 位置 | 改动 |
| --- | --- |
| `visual_instructions`【视觉交谈】 | 事实只取描述里写到的，说法用当前人格平时的口吻和招牌手法：一句答案，再带半句自己的态度或反应；不照念描述、不用换哪个人格都一样的播报腔；围绕本轮问题接话，去掉“已有话题” |
| `_fresh_view_hint`（刚为这一问看到的画面） | 这一问的事实以它为准；它不是用户发言，也不是照念的台词，挑和问题有关的说，用当前人格的口吻；认人仍只按眼前画面，不猜名字 |

## 2. 以当前这句为准

- 新常量 `CURRENT_TURN_RULE`，接在会话指令末尾：回答以用户刚说的这一句（或刚发生的这件事）为准，换了话题就跟着换，前面的对话只用来理解指代和省略；不要把说过的话原样再说一遍。
- `event_policy._IN_CHARACTER` 和雷达靠近提示：去掉“顺着/结合正在进行的话题”，改为只回应这件事本身，不借机把话题拉回之前聊过的内容。
- 内心活动 `thought_prompt`、空闲续聊提示：用自己的话说，不照念提示里的原词。
- 外部事件（经 `submit_text(source="external")` 进来的：事件、空闲续聊/内心活动、提醒）发给模型时附上“你最近说过：「…」。这次换个说法，不要重复这些话。”（最近 3 句，每句最多 60 字）；存库的 `external_prompt` 不变。

## 3. 不重复

识别终稿前 smart_turn 抢先生成、被压住等放行的回复，在 `_release_wake_response` 放行前多两步检查：

| 情况 | 做法 |
| --- | --- |
| 压住了不止一条回复 | 只放最新一条；旧的记入已取消并删掉模型历史里的条目，日志 `wake_response_dropped reason=superseded` |
| 最新一条已完整生成、没有工具调用，去掉标点后至少 4 个字，并且和她最近 6 句里的某句一字不差 | 撤回并删掉这条，补一条内部提示（标明不是用户发言，带上用户刚才这句）后重新 `response.create`，走补答同一套登记（`_recovered_create`）；日志 `repeated_reply_regenerated` |
| 用户这句是“再说一遍/重复一下/刚才说什么/没听清” | 不检查，照常放行 |

## 4. 测试

`tests/test_reply_focus_1103.py`：

- 视觉指令要求事实取描述、口吻取人格；
- 会话指令含 `CURRENT_TURN_RULE`，外部事件附上她最近说过的话、存库仍是原提示；
- 压住两条回复只放最新一条，旧的被删除；
- 压住的回复和上一句一字不差时被撤回并重新生成，内部提示带用户这句；
- 用户要求“再说一遍”时照常放行。

`tests/test_phase8_events.py` 雷达提示断言改为不含“正在进行的对话”、含“不要借机把话题拉回”。
