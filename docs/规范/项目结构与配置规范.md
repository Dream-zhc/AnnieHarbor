# 项目结构与配置规范

目录地图以本文为准；长期硬约束见根 `PROJECT_RULES.md`。当前软件阶段已收束，不因整理目录新增模块或推进阶段。

## 目录唯一职责

```text
brainv2/
├── apps/runtime/          # 唯一Python进程bootstrap、机器人/Session/回合生命周期
├── packages/
│   ├── annie-core/        # 纯类型/状态，无SDK或Graph依赖
│   ├── annie-brain/       # 对话/人格/记忆策略及按需LangGraph
│   ├── annie-adapters/    # SQLite、Room、Realtime、TTS与第三方SDK边界
│   ├── annie-observability/ # Trace与性能诊断
│   └── annie-web/         # FastAPI/静态资源接口，不是第二套前端
├── web/                   # 唯一React/TypeScript工作台及大屏
├── config/                # 非敏感可提交配置、Persona与关键词
├── scripts/               # 模型下载和部署初始化工具，不是临时测试
├── tests/                 # Python长期自动化回归
├── docs/                  # 当前总览、规范、协议与有效证据
└── var/                   # 本机数据库/日志/缓存/模型/临时产物
```

根目录只保留README、AGENTS、PROJECT_RULES、pyproject/锁文件、Python版本、环境模板、启动器和必要生态文件。规划/评审/交接进 `docs/` 的对应目录，文件名优先中文；不新建同义目录、第二套frontend、空目录或占位文件。

## 前后端与实时边界

- `web/src/`承载工作台和数据大屏，`web/tests/`保留回归；共用React/Vite和唯一npm锁文件，不独立部署两份前端。当前URL与构建命令见 [web/README.md](../../web/README.md)。
- Python正式提供 `web/dist/`；Node热更新只用于开发。前端不存Provider密钥，不复制后端状态机；关闭网页后Runtime仍处理机器人PCM。
- GSAP + @gsap/react沿用锁文件精确版本；尊重减少动效、卸载清理与实时并发，不假造波形、不延迟业务、不并装动画引擎。
- Realtime负责普通聊天和Function Calling，独立TTS输出PCM，同一PCM/文本送ForcedAligner；LangGraph只按需处理复杂任务。职责约束见[收束总览](../规划/小安妮V2后端开发总计划.md)。
- 一机器人独占一Room，A/roomv2、B/roomv3；保留原六通道和现有确认的信令/视觉协议，每Room一路连续PCM，不猜target或混流。

## 配置与机器覆盖

| 路径 | 用途 |
| --- | --- |
| `config/app.toml` | 服务默认参数 |
| `config/robots.toml`、`config/rooms.toml` | 机器人实例、独占Room和完整通道映射 |
| `config/providers.toml` | Realtime/TTS/视觉/天气等非敏感Provider设置 |
| `config/runtime_defaults.toml` | 对话、检索、工具等当前业务默认值 |
| `config/personas.toml` | 人格表达素材 |
| `config/action_scripts.json`、`config/attention_scoring.json` | 动作/注意力资产 |
| `config/小安妮唤醒词*.txt` | 中文唤醒关键词；选择方法见[唤醒说明](中文唤醒词配置说明.md) |
| 根 `.env` | 密钥和本机覆盖，永不提交 |
| 根 `.env.example` | 键名、安全示例及说明，不含真实凭据 |

未启用不等于可删除，配置存在不等于health已ready。删除/迁移资产、修改Room语义或换模型先问用户；V1 `skills.json`不迁入。

固定优先级：**CLI > 已导出的系统环境变量 > 根 `.env` > `config/*.toml` > 极少量代码兜底**。Python bootstrap统一读取 `.env`，不覆盖系统环境；启动Shell不另写解析器。全部本地覆盖键以 `.env.example`及当前bootstrap为准。

## 环境与运行数据

Python版本由 `.python-version`固定，主环境只有根 `.venv/`；`pyproject.toml`是依赖真源，`uv.lock`锁解析结果。新依赖需当前用途，不另建主requirements、复制venv或依赖父目录环境。sidecar自身requirements仅服务sidecar。

```text
var/runtime.db       # 本机Runtime SQLite（schema以当前迁移实现为准）
var/pytest/          # pytest cache
var/ruff/            # ruff cache
var/uv-cache/        # 启动器uv cache
var/models/          # 不提交的模型权重
var/tmp/<任务标识>/   # 一次性探针、测试库、音频与快照，用完清理
```

数据库规范化并解析符号链接后仍须位于根 `var/`。运行时不往源码/根目录写日志、缓存或权重；真实数据库、模型、用户资料与其它任务材料不做批量清除。目录随真实用途创建。

## 启动与检查

macOS/Linux用 `sh start.sh`，Windows用 `start.bat`；两者进入同一个 `python -m annie_runtime`，默认端口8780。

替换前先无损预检配置、静态资源、数据库格式/schema/路径。预检失败保留旧服务；目标端口已有经 `/health`证明为同一Annie Harbor的实例才终止旧PID、等待释放并启动新进程。其他占用明确报错，禁止盲杀或静默换端口。直接运行Runtime默认不替换，启动器显式开启替换。

```sh
uv run --locked pytest -q
npm --prefix web test
npm --prefix web run typecheck
uv lock --check
uv run --locked ruff check apps packages tests
```

前端发布改动额外 `npm --prefix web run build`；启动改动额外真实进程+HTTP检查。长期回归在 `tests/`和`web/tests/`，协议fixtures沿用现有归档；临时HTML已删除，不恢复。浏览器和设备人工验收遵守总览WEB-01～08，不用构建/后端通过代替。

临时产物按 `PROJECT_RULES.md`第8条清理；本次用户明确要求的历史测试副本清理保留一份本机可验证回滚包于 `var/整理回滚/20261009/`，不参与运行或Git发布，由用户确认无需恢复后删除。
