## 开工复述（用户 2026-10-26 确认）

```text
本次范围：心情与精力 + 她自己的一天（经历日志）+ 主动开口用上二者 + 对话质量评测脚本；工作台加只读“内心”卡片。
目标与可见效果：她的语气、话量随真实发生的事变化；被问“今天过得怎样/心情怎样/为什么”能如实说；空闲搭话能聊自己今天真实的经历。
输入 → 处理 → 输出：触摸/气味/靠近/认出熟人/记住新脸、每轮用户对话 → 本地规则 + 后台决策模型判断 → 小状态与经历行（SQLite）→ 写进 Realtime 会话提示词、空闲规划器输入、工作台卡片。
必须保留：普通聊天不经过 LangGraph；不加新情绪模型；首响链路不等待任何新调用；8C 面对陌生人不说名字和聊天内容。
本次不做：按人记“上次没聊完的事”、每晚反思、倾听时身体动作、语音情绪模型、双头。
用户决定：经历里的聊天记“一句摘要，带认出的人名”；心情由“本地规则 + 决策模型”判断；工作台加只读卡片。
```

## 做了什么

| 部分 | 实现 | 位置 |
| --- | --- | --- |
| 心情与精力 | 心情值 -1～1（基线 0.15，半衰期 20 分钟回落）、精力 0～1（随北京时间回到基线，每轮对话 -0.012）、最近一次真实原因。白天 45 分钟没人理会变无聊。重启后从 SQLite 恢复 | `packages/annie-brain/src/annie_brain/inner_life.py` |
| 事件影响 | 轻摸/轻按 +0.18，用力拍按“有点被吓到”，突然凑近、闻到气味，认出熟人 +0.25，记住新脸 +0.12。只处理发声策略已接受的事件，松手和按住重复不算 | 同上 `event_feeling`；`apps/runtime/src/annie_runtime/events.py` |
| 对话影响 | 每轮用户对话结束后，后台向决策模型（d3 在线用 d3，否则阿里）问一个选择题：开心/感动/委屈/担心/无聊/平常；置信度低于 0.4 不改，失败不改 | `APPRAISAL_QUESTION`；`realtime.py` `ask_decision` |
| 今天的经历 | 事件各记一行，10 分钟内重复的触摸记成“（共N次）”；一段对话在最后一句 120 秒后结束，用 qwen-flash 写一句“和X聊了……”。X 只来自声纹匹配，或画面里正看着/唯一认出的人；打字输入不安名字。无内容的交流返回 skip | `apps/runtime/src/annie_runtime/inner_life.py`、`packages/annie-adapters/src/annie_adapters/diary_summary.py` |
| 写进会话 | 【你此刻的状态】与【你今天的真实经历】（今天最多 6 行、约 420 字）拼进现有的合并提示词写入通道，只在文字变化时更新；时间说法只分“刚才/不久前/约N小时前”，避免频繁更新 | `realtime.py` `_combined_instructions` |
| 主动开口 | 续聊规划器多一个 mood（含原因）；8C 空闲搭话多 mood 和 own_day，mood 只有心情和精力、不带原因（原因可能含人名），own_day 只有触摸、气味、靠近和“今天有认识的人来看过你”，没有名字和聊天 | `apps/runtime/src/annie_runtime/idle.py`、`packages/annie-adapters/src/annie_adapters/idle.py` |
| 删除 | 删除会话会删掉由它写出的经历；“忘掉我”会删掉写有这个名字的经历 | `on_chat_deleted`、`faces.py` |
| 工作台 | 右栏“内心 · 心情 / 今天”只读卡片：心情、原因、精力、心情值、上一轮判断、当前对话、今天的经历、是否已写进当前会话 | `web/src/inner-life.tsx`、`inner-life-state.ts`；接口 `GET /api/robots/{id}/inner-life` |
| 评测 | 用 `var/runtime.db` 的真实对话按 5 个维度打分，结果写到 `var/tmp/对话评测/` | `scripts/对话质量评测.py` |
| 配置 | `config/runtime_defaults.toml [inner_life]`（默认开）、`config/providers.toml [llm.diary]`；`.env` 的 `ANNIE_INNER_LIFE_ENABLED=0` 可整体关掉 | |
| 数据 | 新增两张表 `robot_inner_state`、`robot_experiences`（纯新增，不改 schema 版本）；运行日志导出脚本也会导出这两张表 | `inner_life_store.py`、`scripts/导出运行日志.py` |

新增模块的四个问题：**当前问题**是她只有说话风格，没有会变的状态和自己的经历；**现有结构为何不够**是 SocialState 只有本轮的对话策略，记忆只存用户的事；**删掉会损失**她能如实讲的情绪和一天；**代价**是每轮用户对话多一次后台决策模型调用（不在首响链路，d3 约 150 毫秒），每段对话结束多一次 qwen-flash 调用，提示词多约 300～500 字。

## 怎么测

1. 重启服务（`sh start.sh`）。心情从上次保存的状态继续，第一次是“平静”。
2. 工作台右栏展开“内心 · 心情 / 今天”，每 4 秒刷新一次。
3. 摸她的头或额头 → 卡片出现“有人轻轻按了你的额头”，心情变好。接着问“你现在心情怎么样？为什么？” → 预期她如实说因为刚才被摸了。用力拍一下 → “有点被吓到”。
4. 夸她（“你今天真厉害”）或说重话 → 回复后卡片“上一轮判断”显示开心或委屈，心情跟着变。预期她能流露一点情绪，但不记仇、不冷淡。
5. 让认得的人（已注册声纹或人脸）跟她聊几句，然后停 2 分钟 → 经历里多一行“和X聊了……”。再问“你今天都干了什么？” → 预期她只讲卡片里有的事。
6. 连续聊三十多轮 → 精力降到“有点累了”，回复应该更短。
7. 画面里有人、空闲一分钟 → 8C 搭话可能提到她自己今天的事（原有门槛不变）。
8. 测完一天后跑对比：`uv run --locked python scripts/对话质量评测.py --since 2026-10-27 --label 内在生活第一版`，和下面的基线比较。

## 待验与风险

- **待真机**：触摸后语气是否真的变化、被问心情能否如实说、经历摘要的人名是否认对、决策模型对心情的判断准不准、提示词变长对首响的影响（未测 P50/P95）。
- 人名只来自声纹匹配或画面认人；没认出时写“一位没认出的人”。认错人时，摘要会写错名字。
- 经历按用户决定带人名，并写进会话提示词。提示词要求“别人的私事不主动讲给旁人”，但有人直接问“今天谁来过”时她会如实说。展厅等公共场景如需避免，可设 `ANNIE_INNER_LIFE_ENABLED=0`。
- 运行日志导出会带上这两张表。在 `main` 提交时，经历摘要会和对话记录一样上传到公开仓库。
- 心情按机器人保存，不随会话或人格切换重置。
- 第二版候选（待用户排期）：按人记待续话题、每晚反思、倾听动作。

### 已用历史对话和真实模型测到的（结果在 `var/tmp/内在生活实测/`）

- **摘要与待续话题**：37 段真实对话 + 8 条正反探针。最终探针 8/8；真实演示对话里没有误提待续话题（之前曾把“帮我查洛阳攻略”“1 分钟后提醒喝水”误当待续话题，已在规则里排除）。了结/记“问过”的探针：qwen-flash 常把“还在准备”误判为已了结（6 次错 5 次），换 qwen3.8-flash 后 4 次全对，所以 `[llm.diary]` 改成 qwen3.8-flash。模型常把已有话题重复写回，已在提示词和代码两处去重。没认出的人一律写“一位没认出的人”，不把对话里自报的名字当成对方。
