# Realtime 文字历史恢复与记忆入口修复

## 用户报告

- 14:45 小安妮问“你平时喜欢怎么放松？”，15:02 用户答“你猜”，机器人却不知道在猜什么。
- 工作台“记忆管理”入口消失，无法查看长期通用、角色与本次会话记忆。

## 根因与修复

1. TTS 启用时，原逻辑对所有会话回合使用 speaker_reported_drained 恢复助手文本；网页文字回合虽然生成并显示，仍被当作没有播完的语音消息。
2. 现已在 SQLite conversation_turns.input_mode 持久化 text、audio、external，Schema 从 8 升至 9，保留所有旧记录。重连时，text 且 completed 的问答按文字恢复；audio 仍以真实播完回执为准。
3. **旧记录默认 unknown，不推断其来自文字或语音**。旧的无播音证据记录仍不当作已经说出；升级后新产生的文字回合可以正确恢复。
4. 工作台恢复“记忆”按钮，重新挂载原有 MemoryPanel，保留三个作用范围和已有记忆增删改查 API；无需复制管理界面，也不删除原 SQLite 数据。

## 验收范围

- text / audio / unknown 三种恢复策略、可重复的 SQLite 升级、同一 Chat 重连历史问答注入、原来的未播语音不复活。
- 工作台按钮可打开记忆管理，并正确传入机器人、Chat、Persona 和 generation。
- 真正跨 15 分钟的人工交流体验、实体扬声器证据一致性仍待人工验收。
