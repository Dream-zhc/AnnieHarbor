# 工作台对话：给视觉模型发画面时显示标识（2026-11-03）

用户要求：给视觉模型发送画面的事件，希望工作台对话里显示一个标识。

```text
本次问题与范围：工作台对话里看不出哪一轮请视觉模型看了画面、看没看成、用了哪个模型，这些只在开发者抽屉的事件里。
目标与用户可见效果：对话里机器人那一行的时间戳前多一个小标识。去看画面时是 👁“看画面中…”（青色、呼吸闪烁），结束后变成“看了画面”（青色）或“没看成”（红色）；只在判断要不要看时带了摄像头画面、最后没去看的轮次显示 🖼“带图判断”（灰色）。鼠标悬停显示路线、模型、描述字数、耗时或没看成的原因。
输入 → 处理 → 输出：主脑 SSE 事件 vision.intent.decided / started / result / abandoned（及抽屉打开时的 diagnostics.turn_events）→ turnVision 按轮次合并去重 → visionBadge 生成图标、文字、提示 → 历史轮和实时轮的机器人行显示。
改动文件：web/src/vision-badge.ts（新）、web/src/workbench.tsx、web/src/api.ts、web/src/styles.css、web/tests/vision-badge.test.mjs（新）、web/dist（重新打包）。
保留项：事件格式和主脑代码不变；开发者抽屉内容不变。
不做事项：大屏展示页不加标识。
结果：tsc 无错，web 测试 139/139 通过，已重新打包 web/dist；刷新工作台页面生效。
```

## 1. 显示规则

| 状态 | 条件 | 标识 |
| --- | --- | --- |
| 看画面中… | 本轮有 `vision.intent.started`，之后还没有 result/abandoned | 👁 青色呼吸 |
| 看了画面 | started 之后 `result.status=ok` | 👁 青色，提示“请视觉模型看画面：云端 · 模型 · 描述 N 字 · 共 X.X 秒” |
| 没看成 | started 之后 result 不是 ok，或 abandoned | 👁 红色，提示“没看成：原因”（如云端视觉超时、用户又说了话） |
| 带图判断 | 没有 started，但 `decided.image=true` | 🖼 灰色，提示“判断要不要看时带了摄像头画面（模型，画面 N ms 前） · 这次没去看” |

没看成的原因按《视觉意图协议》的 `error` 表翻成中文：no_frame、cloud_unavailable、cloud_error、cloud_timeout、local_error、expired、superseded、invalid_request，以及主脑侧的 timeout、send_failed；abandoned 的 turn_changed、realtime_connection。其他代码原样显示。

页面刷新后，历史轮的标识靠主脑内存里的事件重放：最近 512 条事件，打开开发者抽屉时再加上内存里保留的近期轮次时间线（diagnostics.turn_events）。更早的轮次、主脑重启前的轮次不显示标识。

## 2. 改动

- `vision-badge.ts`：`isVisionEvent`、`turnVision`（按 seq 合并 SSE 和 diagnostics 两路事件并去重；result/abandoned 只认 started 之后的）、`visionBadge`。
- `workbench.tsx`：抽屉关着时也保留这 4 种视觉事件（controls 过滤）；历史轮、实时轮的机器人行加 `<VisionBadge>`；还没回复但正在看画面时也显示这一行，底部写“正在看画面…”。
- `api.ts`：`RealtimeEvent` 补 image、judge、model、frame_age_ms、route、chars、total_ms 字段。
- `styles.css`：`.turn-vision-badge` 及 looking/failed/judged 三种状态，含浅色主题。

## 3. 测试

`web/tests/vision-badge.test.mjs` 7 条：看了画面（路线、模型、字数、耗时）、看画面中、没看成（主脑超时、云端视觉超时、用户又说了话）、带图判断及其转为看画面中、没发图或别的轮次不显示、两路事件去重、工作台接线（过滤保留、历史和实时两处标识）。
