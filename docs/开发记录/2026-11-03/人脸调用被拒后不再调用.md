# 人脸录入/遗忘：被拒一次后不再调用（2026-11-03）

用户要求：人脸录入和遗忘保持“规则优先、D3 兜底”（用户选 B），并问能否用阿里模型自带的工具调用（Function Calling）来做录入和遗忘。

```text
本次问题与范围：11-02 晚实测，有人自我介绍后模型调用了 remember_face，听写的名字和规则听到的同音不同字，被拒；之后同一个人又自我介绍三次，模型一次都没再调用。查明录入和遗忘本来就走 FC，漏调是被拒时回给模型的说明把它教偏了。
目标与用户可见效果：被拒只管那一句；之后有人自己报名字或要她记住，照常调用并录入。遗忘问过一次确认后，对方答应就真的删掉。
输入 → 处理 → 输出：识别终稿 → 模型用 FC 调 remember_face/forget_face → _tool_call 规则判断（heard_name / self_introduced / introduces_other），判不准交 D3 → faces.remember/forget → 结果和说明回给模型 → 模型开口。
改动文件：apps/runtime/src/annie_runtime/realtime.py、apps/runtime/src/annie_runtime/faces.py、packages/annie-adapters/src/annie_adapters/realtime.py、tests/test_face_registration.py。
保留项：规则优先、D3 兜底；不替别人录脸；遗忘要确认一次；ANNIE_ADDRESSEE_ENABLED=0 及其默认值不变；上一会话已做的同音字匹配与 already_known / known_as_other 状态。
不做事项：漏调兜底（规则认定是自我介绍但模型没调用时由主脑补一次），等实测后由用户决定。
结果：相关测试通过，全量 1334 通过、6 个失败均与本次无关（见《回复带人格、只答当前这句、不重复》文末）；重启主脑生效；真机待验。
```

## 1. 原因

被拒时回给模型的 `function_call_output` 带着说明文字，旧文案是“请TA说'记住我，我叫……'。不要重试”。这段话留在模型的对话历史里（最多 20 轮），模型把“不要重试”当成以后都别调，于是同一个人后面三次自我介绍都没有调用。同一晚另外 4 次录入都正常调用了。

## 2. 改了什么

| 位置 | 改动 |
| --- | --- |
| `realtime.py` `REJECTED_RULES["remember_face"]` | 去掉笼统的“不要重试”，改为“这一句不要再调用；之后有人自己报名字或要你记住TA，照常调用remember_face” |
| `realtime.py` `REJECTED_REASONS[FACE_FOR_OTHER]` | 替别人报名被拒时加“本人之后自己来说时，照常调用remember_face” |
| `realtime.py` 会话指令人脸段 | 加“画面里没认出TA也照样调用（【认人】只管怎么称呼），前面没记成也不影响这一次”；遗忘改为“TA下一句答应（嗯、对、确定、忘吧，或再说一遍要忘）就马上再调用一次，不答应就不忘” |
| `faces.py` 遗忘确认说明 | 写明对方下一句答应就马上再调用一次 forget_face、name 不变，不要只回一句“好的” |
| adapters 工具描述 | remember_face：被拒只管那一句，下次有人自我介绍照常调用，即使画面里还没认出；forget_face：对方下一句答应就马上再调用，拒绝就不调 |

被拒和确认都不写“不要重试”这类不带范围的话：它们会留在模型历史里，管到后面每一句。

## 3. 测试

- `test_a_refused_face_call_never_stops_the_next_one`：工具描述和会话指令里有新说法；不是自我介绍的一句被拒时，说明里没有“不要重试”“记住我”，有“照常调用remember_face”；替别人报名被拒也一样；随后本人自我介绍照常进入录入。
- `test_forgetting_asks_once_and_a_no_keeps_the_face` 加断言：确认说明里有“嗯、对、确定、忘吧”和“马上再调用一次forget_face”。

## 4. 待定

漏调兜底：规则明确认定是自我介绍（或要忘），而模型这一轮没调用人脸工具时，主脑补一次。建议先重启实测，仍漏调再加。
