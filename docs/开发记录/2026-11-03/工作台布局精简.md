# 工作台布局精简（11-03）

目标与用户可见效果：工作台右侧先放内心和语音状态两块，默认展开；网页麦克风和试听播放器收进一个默认折叠的「网页麦克风 / 试听」面板，功能不变。语音响应延迟从右侧大卡片改成会话头部的一个「延迟 xxx ms」标签，鼠标悬停看明细。会话头部去掉「实时对讲」小字，角色和房间合成一个标签，新建/删除挪到历史会话栏；五张实时卡合成三张：你说的话、对话决策、她的回答。
输入 → 处理 → 输出：机器人实时状态（realtime / speech）→ `latencyMetrics` → 头部延迟标签；ASR 增量、终稿、环境音事件 → 「你说的话」卡（识别中显示增量，否则显示终稿，底部一行显示最近 3 条被忽略的环境音）。

| 位置 | 改动 |
| --- | --- |

| `styles.css` | 新增 `.card-foot`、`.latency-tag`、`.delete-chat`、`.audio-debug-panel`；删掉不再使用的 `.metric-card`、`.metrics-grid`、`.eyebrow`（含浅色主题） |
| `web/dist` | 重新构建 |

## 顺带核对：D3 不判断“是不是对她说”

`.env` 里 `ANNIE_ADDRESSEE_ENABLED=0`，主脑启动时读 `.env`（`__main__.py` 的 `load_local_env`），17:25 启动的进程环境里没有覆盖这个变量。关闭时不创建判定器（`__init__.py` 的 `addressee_judge`），`_addressee_check_needed` 直接返回 False。当天 3 份主脑日志（16:53、17:21、17:25 启动）里 `addressee_decision` 都是 0 次；D3 只做了看画面意图（`vision_intent_decision`）和自动表情（`auto_expression`）。代码里这个变量的默认值是 1，靠 `.env` 关掉，换机器部署时要带上这一行。
