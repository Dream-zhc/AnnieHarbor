# 意图路由合并与规则瘦身（2026-11-26，`dev-next`）

基于 11-25 实测（`docs/开发记录/2026-11-25/d3决策模型实测与新场景.md`）与五类意图的原始回放复核，对 `dev-next` 对话链的意图判断做两段式收敛、单轮批量合并 `ask`、d3 置信度校准，以及严肃/倾诉安全阀接入。**不动 `main` 分支**（`main` 先单独提交 11-25 演示修复与运行日志后保持不动）。

## 1. 改了什么

| 模块 | 改动 |
| --- | --- |
| `decision_policy.py` | `_LOOK_CRITERIA["none"]` 补充“介绍自己、对面前的人说话、打招呼或表演”；新增 `SERIOUS_CONTEXT_QUESTION`、`SERIOUS_CUE` / `serious_cue` 与多题共用的 `turn_intent_state` |
| `language.py` | `_NOT_A_REQUEST` 去掉全局引号误杀，改为 `_language_quoted` 只拦语言名在引号内的情况；`explicit_language_request` 快路径限定 `<=40` 字，长叙述经 `unplaced_language_mention`（取最后一次命名语言）交决策模型；同步 `_intent_once` 修复一句方言不延续到下轮；新增 `mark_serious` 与严肃提示 |
| `speech_expression.py` | `SoundMarks` 新增 `serious` 状态与 `set_serious()`：严肃倾诉时运行时硬清拟声/笑声标记，情绪标签只放行 `empathetic / serious / sad` |
| `config/runtime_defaults.toml` + `__main__.py` + `__init__.py` | `[vision.intent.decision]` 新增 `d3_min_confidence = 0.6`（0～1 校验、启动日志和 `/health` 可见） |
| `realtime.py` | 引入 `_decide_turn_intents` 与 `_run_background_intents`：阻塞批次（`sleep`/`look` 触发时）与后台批次（普通聊天 0ms 阻塞）均将同轮多题合并为单次 `client.ask`；`language` 补判给 d3 加 0.6 置信度门槛（阿里回退不设）并回填 `_language_decision` 供工具复用；`serious` 安全阀仅在 d3 在线且命中线索时异步判断（≥0.6 生效）；`clear_language_preference` 复用 `explicit_language_clear` 删除 4 处重复内联正则；删除独立 `EXPLICIT_MOTION` 正则改为复用 `_motion_command` / `explicit_expression` / `GENERIC_MOTION` |
