# 小头机器人接入大脑（2026-11-18）

用户要求：小头机器人也接入这个大脑，大头和小头同时启用、互不排斥；工作台要看得出每块板子在不在线、是不是正在对话、哪块后上线，后上线时自动切过去并提示。

```text
本次问题与范围：大脑原来只配了大头 annie-a（roomv2）和 B annie-b（roomv3）；唤醒词、云端 AEC、嘴型、摄像头、动作白名单都是全局的，不能按机器人区分；工作台也看不出板子在不在线、哪台后上线。
目标与用户可见效果：小头 annie-small 走独立房间 roomv4，和大头同时在线、各自对话。小头不要唤醒词、不要嘴型，开云端 AEC，摄像头借大头的 LiveKit 房间，只做 6 个动作。工作台机器人按钮有在线圆点和“对话中”“后上线”标签，悬停显示板子和各开关；后上线的板子自动切过去，提示“小头机器人后上线，已切到小头机器人”。
输入 → 处理 → 输出：config/robots.toml 每台开关 → load_robots / RobotConfig 校验 → HarborRuntime 按机器人决定唤醒词、AEC、嘴型订阅、视觉订阅、动作白名单、LiveKit 房间 → /health 的 robots[].switches / head 和 actions.robot_allowlists → 工作台 robot-presence 算在线、对话中、后上线。
改动文件：config/robots.toml、packages/annie-core/src/annie_core/__init__.py、packages/annie-adapters/src/annie_adapters/__init__.py、apps/runtime/src/annie_runtime/（__init__.py、__main__.py、actions.py、motions.py、realtime.py、room_monitor.py）、.env.example、web/src/（api.ts、robot-presence.ts（新）、workbench.tsx、styles.css、room-observations.tsx、developer-drawer.tsx）、web/dist（重新打包）、tests/test_small_head_robot.py（新）、web/tests/robot-presence.test.mjs（新）、tests/test_phase1.py、tests/test_room_observations.py。
保留项：一机器人一独立 Room；大头、B 的房间不变，B 不写新开关（全取默认值）；动作名不变；用户的 .env 不动。
不做事项：脑内大头/小头互斥、按机器人 AEC 标定、动作改名、Windows tts_viseme 和板子端代码。
结果：pytest 1397 passed（另有 4 个 room-speaker 测试文件因工作区删了 room-speaker/ 无法收集，与本次无关）；web 测试 147/147、typecheck、build 通过；ruff 与 uv lock --check 通过；隔离根 sh start.sh 空闲端口真实拉起，工作台 200、/health 503（Room 故意不可达），三台机器人的 switches / head 正常输出。正在跑的大脑要重启才会接 roomv4。
```

## 1. robots.toml 每台开关

| 开关 | 默认 | 作用 |
| --- | --- | --- |
| `wake_enabled` | true | false 时不挂唤醒词检测，Room 音频直接进实时全双工 |
| `aec_enabled` | false | 云端回声消除；还要本机 .env 的 `ANNIE_CLOUD_AEC_ENABLED=1` 总开关 |
| `mouth_enabled` | true | false 时不订阅本房间 `reb_sam`，嘴型状态为 `disabled`，工作台显示“已关闭”，启动时的嘴型在线探测也不再为它告警 |
| `camera_enabled` | true | false 时不订阅本房间的 visualllm 视觉描述（视觉描述和“先看再答”都依赖它） |
| `actions` | 空，用全局白名单 | 这台机器人能做的动作 script_id；启动时逐个在动作目录里校验，不存在直接报错，重复也报错 |
| `livekit_room_of` | 空 | 本机没配 `ANNIE_EXHIBIT_LIVEKIT_ROOM_<ID>` 时借用哪台机器人的 LiveKit 房间；不能指向自己或文件里没有的机器人；单独配了房间变量的优先 |

当前配置：

- annie-a（大头，roomv2）：新增 `aec_enabled = true`，其余取默认。
- annie-b（roomv3）：不变。
- annie-small（小头，roomv4）：`wake_enabled = false`、`aec_enabled = true`、`mouth_enabled = false`、`camera_enabled = true`、`livekit_room_of = "annie-a"`、`actions` 为 shake_head、look_left、look_right、fast_double_blink、wink_left、wink_right。

## 2. 后端改动

- **AEC 选哪几台**（`__main__.cloud_aec_robots`）：以前 `ANNIE_CLOUD_AEC_ENABLED=1` 时按 `ANNIE_CLOUD_AEC_ROBOTS`（默认 annie-a）选；现在总开关不变，选哪几台由 `aec_enabled` 决定（当前 annie-a、annie-small）。旧变量还在且和 robots.toml 选出的不一致时，启动打 warning 并忽略：`ANNIE_CLOUD_AEC_ROBOTS=annie-a is ignored; robots.toml aec_enabled selects annie-a,annie-small`。
- **唤醒词**：`wake_enabled = false` 的机器人不传唤醒词检测器给 Realtime。
- **嘴型**：`mouth_enabled = false` 时不建 `sam` 监听；`RoomMonitor` 的 viseme 状态报 `disabled`；启动嘴型探测和 /health 汇总都把 `disabled` 当作“没配”处理，不算离线。
- **视觉订阅**：以前 roomv2 总订阅 visualllm，其它房间只有开了空闲主动说话（idle）且有 Realtime 时才订阅；现在改为 `camera_enabled` 的机器人订阅自己房间的 visualllm（roomv2 没有 Realtime 也订阅，其它房间要有 Realtime），不再要求 idle。当前 .env 开着 idle，B 的实际订阅不变；只有关掉 idle 时，B 才会多订阅 roomv3 的 visualllm。
- **LiveKit 画面**：机器人没单独配房间时按 `livekit_room_of` 借用（小头用 annie-a 的）；共用同一个房间的机器人只开一路 `LiveKitFrames` 订阅。
- **动作**：`ActionCoordinator.allowed(robot_id)` 有 robots.toml `actions` 就用它，否则用全局白名单。真实执行校验、Function Calling 的动作列表、提示词里的“你能做的动作”、看/转头、自动表情、互动动作（倾听、说话、内心）都按机器人取。
- **/health**：`robots[]` 每台新增 `switches`（wake、aec、mouth、camera、actions，按实际生效：wake 要有 Realtime 和唤醒词检测器，aec 要本机总开关）和 `head`（板子心跳报上来的当前板子，没有板子时为 null）；`actions` 新增 `robot_allowlists`。

## 3. 工作台

- `robot-presence.ts`（新）：名字取板子的 `head_name`，没有就用 robot_id；“对话中”= ready 且正在回答、正在听到有人说话、正在播 TTS，或 30 秒内听到过人说话；“后上线”= 在线板子里上线时间最短的那台，至少两台在线才标；悬停文字按行列出板子名字、地址和唤醒词、回声消除、嘴型、摄像头、动作数。
- `workbench.tsx`：首次打开直接选中最后上线的那台，不弹提示；之后每次刷新 health 发现新上线的板子（robot_id/instance_id 变了，重启也算）就切过去并提示“X后上线，已切到X”；手动切回不会再被拉走，板子下线也不切回。机器人按钮加状态圆点（绿在线、灰离线）和“对话中”“后上线”标签。
- `api.ts` 补 `switches`、`head`、`realtime.speech_active` 类型；`styles.css` 加 `.robot-pill-tag` 及浅色版；`room-observations.tsx`、`developer-drawer.tsx` 把嘴型 `disabled` 显示为“已关闭”。

## 4. 测试

- `web/tests/robot-presence.test.mjs` 5 条：在线、对话中、后上线、自动跳转等判断。
- 调整的旧测试：`test_phase1.py` 机器人列表断言加上 annie-small；`test_room_observations.py` 里 roomv3 的机器人 b 设 `camera_enabled=False`，视觉订阅不再依赖 idle 后，用它保持该用例“roomv2 的订阅不串到 roomv3”的原意。

## 6. 上线注意

- 正在跑的大脑要重启才会听 roomv4。
- 小头板子：复制 `sidecars/annie-room-audio`，`room-audio.env` 设 `SPEAKER_ROOM=roomv4`（必须，否则和大头同房间，后启动的会把大头停掉）、`ROBOT_HEAD=small_head`、`ROBOT_HEAD_NAME=小头机器人`，声卡按 `sh annie-audio.sh devices` 填。小头的动作端连 roomv4 的 reb_main。
- .env 里的 `ANNIE_CLOUD_AEC_ROBOTS` 已不生效，可以删掉；不删只是启动时打 warning。
