- 总计划只保留现行边界、摘要和验收规则；删除已结束的重复实施计划、源码快照和命令转储。
- 阶段 README 保留可核对的实际结果和待验项；协议/fixture不因精简而删除。
- 长期回归在 `tests/` 与 `web/tests/`；旧临时 HTML 不恢复，正式人工测试使用既有 React 工作台。
- 一次性探针放 `var/tmp/<任务标识>/`，用完清理；不扫空 `var/`，不动运行数据库、模型、密钥和用户资料。
