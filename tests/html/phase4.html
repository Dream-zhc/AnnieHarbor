Phase 4 · 正式工作台 / Realtime

本页仅列出真实验收入口和操作步骤，产品功能全部在同一 React 工作台。

4-工作台

打开正式 React 工作台 →
  1. 在不同机器人间切换，确认 Room、PCM 计数和健康状态分别归属正确机器人。
  2. 新建及切换同名 Chat/Persona，检查旧消息仍保留，当前有效上下文最多 20 轮。
  3. 取消删除、确认删除分别验证，确保未删除其他机器人或 Persona 的记录。
  4. 选定 Room 并确认无第二音源，再发送一帧测试 PCM；对比目标 Room accepted 是否增长。
  5. 开启麦克风、切换机器人、关闭页面；确认采集停止、不转发到新 Room。
  6. 禁用网络、缺少构建文件分别复核错误可见、失败不误杀旧 Runtime。

自动化测试不代表桌面/窄屏浏览器或物理麦克风验收通过；正式文字区只在 Provider ready 时接受真实请求，独立 Fake 功能在开发者区。

4-Realtime｜需要人工验收的真实语音链路

进入工作台，选机器人检查 Realtime ready →
  1. 在 roomv2 确认无第二音源，开启浏览器麦克风，说一句短话；查看目标机器人 frames_sent、转写、smart_turn 和完整文字回复，确保 roomv3 不变。
  2. 在 roomv3 重复，再分别连续说两轮，检查当前 Chat 的上文、Persona 与完整 Ledger；在工作台观察连续增量，不用 Fake 回显顶替。
  3. 测试“嗯”等附和、正常新发言与手动提交冲突，观察 invalid 标识、是否重复创建 response。
  4. 切 Chat/Persona、取消当前回复，检查旧 generation 的迟到文本未串入；按实际需要测试断网与自动重连。
  5. 发出一个动作请求，在工具原始记录里确认仅模拟执行、参数校验及后续文字，真实设备没有动作。

当前无 TTS、播放回执或嘴型；请分别记录真实 Room 帧、Provider 首文本和浏览器体验，未操作的项目写待验。
