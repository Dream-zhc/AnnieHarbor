# 声纹注册

2026-10-12。用户要求在设定里用麦克风登记姓名，声纹全局保存，并让当前这句话的模型知道是谁在说。

## 实现

- 登记在工作台「设定 → 声纹注册」。录音 3–12 秒，或上传 wav/mp3/m4a，再填写名字。名单不按机器人或 Chat 分开。页面麦克风正在听时，再录一次可能是空白，会提示太轻。
- 声纹向量写入现有 SQLite `speaker_profiles`，重启仍在。原始 WAV 不入库。
- 识别用本机 sherpa campplus，不使用云端 `voiceprint_audio_urls`。那条接口只加强目标声音，不会返回姓名。
- 说话约 1 秒后开始比对，说完后再对一次。匹配结果写入本轮会话指令：模型知道这句话是谁说的，只在语境自然时称呼，不每句宣布。太短则短时间沿用上一句；没对上或两个人太接近时不点名。
- 模型文件：`var/models/3dspeaker_speech_campplus_sv_zh-cn_16k-common.onnx`。下载命令 `uv run --locked python scripts/下载声纹模型.py`。文件不存在时对话照常，登记接口说明原因。

## 验证

- `uv run --locked pytest -q`：875 passed，42 subtests。
- `npm --prefix web test`：103 passed。`tsc --noEmit` 通过。
- 隔离进程 `127.0.0.1:18796`，不连接真实 Room。Chromium 假麦克风完成登记「小明」、刷新后名单仍在、删除后为空。390 宽对话框没有横向溢出。
- 该页没有接入 Realtime，所以页面显示「还没有识别结果」。指令注入由 `tests/test_speakers.py` 用假声纹向量验证。真人误识率和现场称呼仍待实测。默认相似度门槛 0.50，可用 `ANNIE_SPEAKER_THRESHOLD` 调整。
