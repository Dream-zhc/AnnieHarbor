## 1. 判断回不回答的两层

| 层 | 做什么 | 今天（10:52–14:20，语音 74 轮） |
| --- | --- | --- |
| 阿里 smart_turn | 每句话说完判断这一轮“有效 / 无效（turn_invalid）”；无效的云端不回答 | 判无效 85 句：追问窗口 61、刚唤醒 9、她说话期间 15 |
| 运行时补救 | 判无效但像是对她说的，等识别终稿和 0.6 秒安静后补问 | **以前只救点名的、刚由唤醒词唤醒的第一句、追问窗口里的**：她说话期间（ACTIVE）15 句、刚唤醒后的不点名句 3 句**直接丢掉，不经任何判断** |
| 决策模型（d3） | 追问窗口里不点名的话判断是不是对她说的 | 判 79 次：对她说 45、旁人 34 |

被直接丢掉的 18 句里有“右边看”（11:16:38）、“上面有啥”（11:17:10）、“你介绍的不对，不”（11:18:50）、“你介绍的还是不对”（11:19:03）、“烤鸭得生吃才”（11:20:10）、“你退下”（11:24:50）、“希望这个会画一直用”（13:52:37）、“你认为自己是个机器人”（13:54:42）等，用户只能重复或打字；也有同事说话（“这发了张玲，你要不看一下”“电锯还是啥没通，你看”）。这是“ASR 显示了但不回答”的大头。

决策模型这一层今天判错的主要是：“从1数到。”(0.21)、“从1数到10。”(0.45)、“你从1数到。”(0.42) 连续三次判成旁人（前一句她刚答完“会啊，一二三四五”）；“我要1.5米。”判成对她说 (0.44) 而回了。d3 判“旁人”且置信度低于 0.5 的共 12 句，其中真是对她说的只有这 3 句，其余是“魔法。”“吗？”“你。”“이제.”“直接点这个是吧？”等碎句和同事说话——按置信度放行会多回 7 句，不划算，所以这次不动 d3，只记录样本，后续可连同 10-21 的标注一起重评。

## 2. 修改

- **她说话期间、刚唤醒后被判无效的话也补判补答**（`realtime.py` turn_invalid）：她说话期间（ACTIVE）和追问窗口一样交决策模型判断，判对她说就打断当前回复并回答，判旁人就忽略、她接着说；刚被唤醒（WAKE_WAIT）不点名的话和唤醒窗口一样视为对她说，直接补答。点名的话、说出已启用动作的话（“右边看”）不再问决策模型。判无效时她照常续播，等判断出结果才停，不会卡住。
- **她说话期间也用“追问版”问题**（`_decide_addressee`）：10-21 评测里这版 d3 准确率 87%、原问题 72%；qwen-flash 同样用追问提示词。
- **问哪边有什么就看哪边**（`decision_policy.py`）：以前只认“往左看 / 看看左边”。现在：
  - “看 / 看看 / 看一下 + (你的)… + 左边 / 左手边 / 左侧”：“那你看看你的你的左手边。”；
  - 句首“左边 / 左手边 / 右侧 / 上面 / 头顶 + 有什么 / 有啥 / 是什么 / 有没有”或“右边看”：“左手边有有啥？”“上面有什么？”；放在句首才算，“桌子上面有什么”不会让她抬头；
  - “转头看看”这类没说哪边的，取用户前 3 句里指过的方向（11:23 那句会看左边）；“旋转头了吗？”是问句不算。
  - 不动的：“你的左边没有饮水镜。”（陈述）、“你左右看…”（两边）、“看看你的左手。”（手）、“左边看起来有点乱”、带“别/不要”的。
  - 用今天原话重放：11:16 右边看、11:17 上面有啥/上面有什么、11:22 左手边有有啥、11:22 看看你的你的左手边、11:23 转头看看 都会转头；“你眼前有什么？”没有正前方的动作脚本，仍不动。
- **识别终稿一到就显示**：补判要等 0.6 秒安静再加决策模型约 0.3 秒，以前这段时间工作台只显示云端没跟上的半句（如“小爱您”），再一下子跳出整句。现在终稿一到就发 `transcript.final_preview`，工作台作为“ASR 暂定”立即显示整句；判成旁人时工作台清掉这段暂定文字（`workbench.tsx`），大屏按原协议收到同 `item_id` 的忽略事件。
- **识别时延日志**：`turn_started` / `turn_invalid` 增加 `first_delta_ms`（云端起声到第一段识别文字）和 `deltas`（识别增量条数）。下次再觉得识别显示慢，看这两个值就能分清是云端识别慢还是本地。

## 3. 查清但没改的

- **漏字是云端识别 / 断句，不是丢音**：两句的 `input_lost_frames` 都是 0。14:10 那句云端流式识别第一段就是“介绍一下你自”，前面“用陕西话”没有任何识别结果；13:46 云端在“语”后判定说完，后面的话没有产生新的语音项。smart_turn 不接受 `threshold/silence_duration_ms` 等参数（10-13 实测），改 server_vad 会失去语义判停和环境音过滤，需要用户决定后再试。
- **断成两半的整句**：13:52“希望这个会话一直用陕西方言输出”被切成“希望这个会画一直用”（判无效）+“输出。”（有效），后半句被云端单独回答成“输出啥？”。前半句现在会被补判，但后半句是有效轮时云端已经开始按后半句回答，把两半合成一句需要撤回云端的回答再补问，改动较大，这次没做。
- **答非所问**：13:48“来一句日语。”回成“左边有啥东西？我看看。”——实时模型直接听音频作答，和识别文字不一致；13:50“语速快一点。”已调用语速工具（`update_chat_preference`），只是随后那句话接回了上个话题。都是模型行为。
- **13:42“我要1.5米。”被回答**：d3 判对她说（0.44）。10-21 评测结论是低置信度的“对她说”也常是对的，不能用阈值收紧。
