# 数据大屏监听接口（reb_display）

> 给大屏前端的接口速查，2026-10-21。完整背景、其它设备通道见 [数据大屏数据同步说明](数据大屏数据同步说明.md)。大屏只读不写：不要往这条通道发业务消息。

## 1. 连接

| 机器人 | 地址 |
| --- | --- |
| A（roomv2） | `ws://192.168.1.47:8090/robot/roomv2/reb_display` |
| B（roomv3） | `ws://192.168.1.47:8090/robot/roomv3/reb_display` |

握手（所有 Room 通道都一样）：

1. 连上后先收到 `{"type":"WELCOME","ok":true,"room":"roomv2","robotId":"reb_display",...}`
2. 发送 `{"type":"SUBSCRIBE","data":{"types":["*"]}}`
3. 收到 `{"type":"ACK","data":{"what":"subscribed",...}}` 后开始收业务消息

断线后等 1～15 秒重连并重新握手。`WELCOME`、`ACK` 和认不出的 `type` 都忽略。

## 2. 消息格式

只有一种业务消息 `display.event`：

```json
{
  "type": "display.event",
  "description": "中文说明",
  "ts": 1792571234567,
  "data": {
    "sender": "brain",
    "robot_id": "annie-a",
    "room_id": "roomv2",
    "event": "decision",
    "...": "各事件自己的字段，见下表"
  }
}
```

按 `data.event` 分发。`ts` 是毫秒时间戳。所有字段都可能为 `null`，界面要容错。

## 3. 事件一览

| `event` | 用途 | 字段 |
| --- | --- | --- |
| `wake.state` | 唤醒灯（休眠/已唤醒/对话中/等追问） | `enabled` `state` `candidate_speech` `deadline_remaining_ms` `last_keyword` `error` |
| `transcript.delta` | 访客字幕中间结果（整段替换） | `item_id` `text` `stash` |
| `transcript.final_preview` | 访客字幕即将定稿 | `item_id` `text` |
| `turn.started` | 一轮对话开始 | `turn_id` `user_text` |
| `text.delta` | 小安妮回复正在生成（整段替换） | `turn_id` `text` `delta` |
| `text.done` | 回复正文结束 | `turn_id` `text` |
| `turn.done` | 一轮结束 | `turn_id` `text` `status` |
| `playback.state` | 扬声器播放状态 | `turn_id` `state` `source` |
| `speech.ignored` | 听到了但没回的话 | `item_id` `text` `reason` `reason_label` |
| `decision` | 简单决策：这句话对谁说、要不要做表情 | `decision` `result` `choice` `confidence` `judge` `model` `latency_ms` `summary`，另见下 |
| `action.state` | 动作/表情指令进度 | `call_id` `turn_id` `action_kind` `action_value` `status` `generation` `real_device_executed` |
| `session.ready` | 实时模型已连接（显示在线） | 无 |
| `session.error` | 实时模型异常 | `error` |

### wake.state

| `state` | 显示 |
| --- | --- |
| `enabled=false` | 免唤醒 |
| `SLEEP` | 休眠，等待唤醒 |
| `WAKE_WAIT` | 已唤醒，等待提问（`candidate_speech=true` 显示“正在听”） |
| `ACTIVE` | 对话中 |
| `FOLLOWUP` | 等待追问，`deadline_remaining_ms` 为剩余毫秒 |
| `error` 非空 | 唤醒异常 |

```json
{"event":"wake.state","enabled":true,"state":"FOLLOWUP","candidate_speech":false,"deadline_remaining_ms":17000,"last_keyword":"小安妮","error":null}
```

### playback.state

`state`：`playing` 正在播，`held` 有人说话暂停，`stopped` 被打断/停止，`drained` 这句播完。`source`：`speaker` 实体扬声器，`browser_test` 网页试听（不代表机器人发声）。只在变化时发。

```json
{"event":"playback.state","turn_id":"58fe824c…","state":"playing","source":"speaker"}
```

### speech.ignored（“忽略”列表）

| `reason` | `reason_label` |
| --- | --- |
| `not_addressed` | 不是对机器人说的 |
| `ambient_audio` | 实时模型判为环境音 |
| `self_echo` | 机器人自己的回声 |
| `turn_invalid` | 实时模型判为不完整 |
| `asleep` | 休眠时听到 |

```json
{"event":"speech.ignored","item_id":"item_…","text":"他没接视觉吧","reason":"not_addressed","reason_label":"不是对机器人说的"}
```

### decision（简单决策）

两种 `decision`：

| `decision` | `result` | `confidence` | `judge` / `model` | `summary` 示例 |
| --- | --- | --- | --- | --- |
| `addressee` 这句话对谁说 | `robot` 回复 / `not_robot` 不回复 | 0～1，判断失败时为 `null`（按回复处理） | `d3` / `d3-NVFP4`、`llm` / `qwen-flash`、`decision` / `decision-model-preview` | 对机器人说，回复 / 不是对机器人说的，不回复 |
| `expression` 要不要自己做表情 | 采用的表情脚本或 `none` | 0～1，低于门槛不采用 | `decision_model` 等 / 模型名 | 做表情 smirk / 不做表情 |

`addressee` 另有 `item_id`、`text`（被判断的那句话，和字幕、`speech.ignored` 用 `item_id` 对上）；`expression` 另有 `turn_id`。

```json
{"event":"decision","decision":"addressee","item_id":"item_…","result":"not_robot","choice":"other","confidence":0.85,"judge":"llm","model":"qwen-flash","latency_ms":290,"text":"这个速度变快了","summary":"不是对机器人说的，不回复"}
{"event":"decision","decision":"expression","turn_id":"58fe824c…","result":"none","choice":"smirk","confidence":0.48,"judge":"decision_model","model":"d3-NVFP4","latency_ms":118,"summary":"不做表情"}
```

建议大屏显示一行：`summary` +（`confidence` 百分比）+ 小字 `model`，例如“不是对机器人说的，不回复 85% · qwen-flash”。

### 字幕的对应关系

- 访客：`transcript.delta`（同一 `item_id` 整段替换，`stash` 灰色接后面）→ `transcript.final_preview` → 定稿以 `reb_voice` 的 `transcript.done` 为准；被忽略的会再来一条同 `item_id` 的 `speech.ignored`。
- 小安妮：`turn.started` → `text.delta`（同一 `turn_id` 整段替换）→ `text.done` → `playback.state` → `turn.done`。

## 4. 当前是哪个机器人头

不在 `reb_display`，在 `reb_voice`（同样握手，订阅 `*`）：`type` 为 `robot.head.active`，每 2 秒一条，`data.head_name`（大头机器人 / obj 娃娃小机器人）、`data.address`（板子 IP）、`data.active_for_ms`；切换时有 `robot.head.released`，`data.reason` 为 `taken_over` 时 `data.taken_over_by` 是接管的头。

## 5. 最小接入代码（浏览器）

```js
function listen(room, channel, onMessage) {
  let delay = 1000;
  const open = () => {
    const ws = new WebSocket(`ws://192.168.1.47:8090/robot/${room}/${channel}`);
    ws.onmessage = (raw) => {
      const msg = JSON.parse(raw.data);
      if (msg.type === 'WELCOME') ws.send(JSON.stringify({type: 'SUBSCRIBE', data: {types: ['*']}}));
      else if (msg.type === 'ACK') delay = 1000;
      else onMessage(msg);
    };
    ws.onclose = () => { setTimeout(open, delay); delay = Math.min(delay * 2, 15000); };
  };
  open();
}

listen('roomv2', 'reb_display', (msg) => {
  if (msg.type !== 'display.event') return;
  const d = msg.data;
  switch (d.event) {
    case 'wake.state':      /* 唤醒灯：d.state */ break;
    case 'playback.state':  /* 播放：d.state, d.source */ break;
    case 'speech.ignored':  /* 忽略列表：d.text, d.reason_label */ break;
    case 'decision':        /* 决策：d.summary, d.confidence, d.model */ break;
    case 'transcript.delta':/* 访客字幕：d.item_id, d.text + d.stash */ break;
    case 'text.delta':      /* 回复字幕：d.turn_id, d.text */ break;
  }
});

listen('roomv2', 'reb_voice', (msg) => {
  if (msg.type === 'robot.head.active') { /* 当前头：msg.data.head_name, msg.data.address */ }
});
```
