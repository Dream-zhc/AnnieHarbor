# 提示词精简与性格重写

> 2026-10-13，用户要求按建议精简通用提示词，并重写六种性格，让每种性格更突出、各有特色。本文记录改动原则、四轮真实云端对比和遗留项；它不是人工听感验收。

## 结论

- 提示词加工具定义合计 **11101 → 8814 字（-21%）**：系统指令 2732 → 2247，工具定义 8369 → 6567。统计配置为实体动作、天气、音色、语言工具开启；记忆和唤醒词关闭。
- 同一模型（3.1-plus）、同样 20 道通用题对比旧版：
  - 无工具首字 P50 持平（187ms），P95 从 411ms 降到 244ms；
  - 回复总字数 787 → 706，最长一条 202 → 131 字；
  - 动作、提醒、天气三类工具调用仍为 3/3；
  - 口头禅重复、保险话和算式符号都降为 0。
- 六种性格重写后，活泼俏皮、机灵互怼、怨种搭档、优雅乐子人在同一道题上能明显区分。自然陪伴和温柔知心在“疲惫、出状况、焦虑”这类题上仍接近默认的关照语气，见遗留项。

## 改动

| 位置 | 改动 |
| --- | --- |
| 工具描述 | 音色、性格、动作、表情、提醒、语言、退下等 9 个描述去重压缩；保留“只有 selected/scheduled/accepted 才算成功、不得口头宣布没发生的变化、不猜 ID、动作锚点”等约束 |
| 运行时规则段 | 实体动作说明从约 850 字压到约 360 字，和工具描述、人设工具边界不再三处重复；音色、退下说明同步压缩 |
| 核心人设 | 保留被回归锁定的全部语义；改成正面写法；删去与核心段重复的外语跟随句 |
| 性格位置 | 性格段移到核心人设之后，并说明“让人一听就认得出，描述里的手法每次现编，不原样复用描述里的词句” |
| 语音输出 | 默认像面对面聊天：一次一个重点、两三句收住，追问/要求详细/倾诉时再展开；不主动列步骤，不加“当然还要看情况”，数字和算式按口语读 |
| 性格文本 | 六种都写成“身份感 + 招牌手法 + 立场/喜恶 + 节奏 + 收尾 + 严肃时切换”，只描述手法，不写可照抄的示例句；ID、名称、500 字上限不变（266～311 字） |

回归测试同步更新：

- `test_persona_style_presets` 改为校验新特征词、各自的严肃切换语和“不含可照抄的引号示例”；
- `test_phase5` 与 `test_persona_style_switch` 改用新版特征词；
- 新增“性格段要求每次现编”的检查。

## 过程中纠正的两件事

1. **硬字数上限与 Phase 5 决策冲突。** 上一版加入的“闲聊和倾诉一到三句、六十字以内”，与 Phase 5 有意移除“普通闲聊通常一到三句”的决定冲突（当时的理由：倾诉可以展开，控制的是价值，不是字数）。第一轮改成纯“按价值控制长度”后，3.1-plus 回复总字数涨了 51%，还出现分步骤建议、保险话和“380 × 0.75 = 285”这样的符号。最终版本是“默认两三句，追问/倾诉/讲解时展开”，再加上三条具体禁止项。
2. **模型会照抄示例句。** 第一轮性格里写了“把烧糊的锅叫‘黑暗料理事故现场’”“据现场观察……”“这事咱一起扛”等示例，实测被原样搬进回答，严肃切换语也被用在不严肃的场合。第二轮起改为只描述手法，并在性格段统一要求“每次现编”，照抄随之消失。

## 遗留

1. 自然陪伴在关照类题目上仍偏向默认的安慰和建议，“先说一个具体发现”执行不稳；加强的写法实测无效，已撤回。需要用好奇或观点类题目听测后再定。
2. 温柔知心第四轮能接住原词并询问对方需要什么，但仍偶尔给小建议。
3. 失眠一类倾诉仍会附一两条小建议（不再列步骤）。
4. 每种性格只测了 5 道题，没有经过 TTS 听感、长对话人格稳定性和真实机器人检验，需要用户人工确认。
