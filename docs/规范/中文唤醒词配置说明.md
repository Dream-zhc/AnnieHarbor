## 两套配置

**默认生产配置（完整词近音）**：`config/小安妮唤醒词.tokens.txt`。2026-10-09依据用户四段真人录音，在原词基础上只增加一条完整三字近音，不开放短词：

```text
x iǎo ān n ī :1.5 @小安妮
x iǎo ài n ǐ :1.5 #0.25 @小安妮
```

**用户提供的宽松实验配置**：`config/小安妮唤醒词_宽松实验.tokens.txt`，完整保留用户给出的14条发音变体、Boosting和触发阈值，**不会默认开启**。默认版仅两条完整三字发音、Boosting为1.5；近音行阈值固定0.25，不使用短词或0.04低阈值。

四段真人录音在原配置命中2/4，默认两条完整发音配置命中4/4；这是同批小样本回放，不是总体准确率或真实环境误唤醒率。已命中的两段没有提前。确认等待从1个blank降到0、输入批次40ms改为20ms，四段命中位置均不变，因此未修改这两个生产参数。详见`docs/开发记录/2026-10-09/唤醒延迟与真人录音复测.md`。

要测试实验文件，在当前机器的`.env`中设置：

```text
ANNIE_WAKEWORD_ENABLED=1
ANNIE_WAKEWORD_KEYWORDS=config/小安妮唤醒词_宽松实验.tokens.txt
```

恢复为默认文件则改为`config/小安妮唤醒词.tokens.txt`，重新启动Runtime加载模型。

### 实际选择入口（本机 .env）

当前本机已启用 sherpa-onnx，默认路径保持不变，文件内容已改为两条完整发音：

```dotenv
ANNIE_WAKEWORD_ENABLED=1
ANNIE_WAKEWORD_MODEL=var/models/sherpa-onnx-kws-zipformer-zh-en-3M-2025-12-20
ANNIE_WAKEWORD_KEYWORDS=config/小安妮唤醒词.tokens.txt
ANNIE_WAKEWORD_THRESHOLD=0.25
```

要选择另一组关键词，**只修改 ANNIE_WAKEWORD_KEYWORDS 的路径**，重启服务后生效；不需要编辑Python源码。关闭唤醒功能则改为 ANNIE_WAKEWORD_ENABLED=0，关掉后不再阻断普通的 Qwen PCM。

本地 `.env` 含 API 密钥并被Git忽略；请勿将整个文件粘贴到公开聊天、Issues 或日志。自训练组件和配置已按用户要求删除，不影响上述 sherpa-onnx 功能。

## 参数与语义

- `:1.5`：默认词的适度Boosting Score；实验版的`:3.0`更加激进。该值并非模型概率。
- `#0.04`：**该关键词自身**触发阈值，覆盖全局默认阈值；低值可能在电视、人声与近音词上导致严重误唤醒，不能因为`ANNIE_WAKEWORD_THRESHOLD=0.35`就认为这些行仍受0.35保护。
- `@小妮`：解码结果输出的标签。用户示例中以`x iǎo ān n ī`代表的实际发音仍是“小安妮”，标签写“小妮”仅影响事件显示，不意味着模型学会了正确检测“小妮”两个字。短关键词`x iǎo ān`及`ān n ī`会接受部分称呼，造成较高旁人误触发风险。
- 这些变体中的`x iǎo ài...`和`x iǎo ān l ì`并不是“小安妮”的同音调发音，是额外模糊匹配；仅保留做A/B评测，不能认为模型天然懂用户昵称。

**验收顺序**：先对比“小安妮”、真实用户口音和同气息提问的召回率，再长时间测试电视/旁人聊天/“小安、安妮”等近音负样本的每小时误触发；以数据决定是否放宽默认配置。单次静音或合成音频触发不代表准确率达标。

排障接口：`/api/robots/annie-a/wakeword`。`decoded_batches`持续增长才证明后端KWS正在解码；`input_dbfs`为KWS**真实收到**的100ms PCM电平（连续`near_silence=true`提示近静音）；`keywords_file`与`global_threshold`是实际加载的配置。`wakes=0`但解码与电平正常，才考虑阈值/发音问题；如果近静音，先排除浏览器输入设备错误、麦克风系统静音与USB接收器输出过低。更改关键词或阈值必须重启Runtime，网页发帧数不能证明KWS命中。
