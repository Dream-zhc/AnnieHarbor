# 小安妮 V2｜开发收束总览

> 更新：2026-10-09。本文替代冗长的历史实施任务卡，保留当前架构、业务边界与验收规则；详细实际证据按阶段查询。
> **2026-10-08软件阶段规划已收束，Phase 10/11及所有后续阶段暂停。** 后续由用户统一实测，仅对暴露的具体 Bug 最小修复，不自动新增功能。软件接线不代表真机、浏览器或连续运行已验收。

## 当前目标与边界

目标是低延迟、上下文连贯、人格稳定、少而准的记忆和合适的陪伴表达，不以模块、Agent、Graph节点或提交数量衡量效果。

- 一个 Python Runtime 管多个机器人，每个机器人独立队列、Session、取消、音频时钟和可变状态，无全局回合锁。
- 一机器人独占一个 Room：A→roomv2，B→roomv3；每个 Room 全量保留 `main/tts/mic/visualdata/vision/sam` 六通道，每 Room 只有一路连续 PCM 输入。额外信令/视觉通道按已确认协议接线，不替代原六通道。
- 本期不做同房间多机器人、多音源混流、说话人分流或猜测设备目标；`from/conversation_id` 不当设备寻址字段。
- `.env`、非敏感配置、用户资料与未启用的已确认资产继续保留。配置存在、模拟通过、真实连接及设备通过分别描述。
- 保留单头 ForcedAligner 和 Phase 9 低频诊断，不做双头嘴型；旧仓库只读，不搬 RobotBridge、不依赖父目录代码或环境。

## 现行架构

```text
所属 Room 的 PCM
  → 每机器人 Audio Input Gate / 唤醒与对话准入
  → Qwen-Audio 3.0 Realtime Flash（ASR / smart_turn / 对话 / Persona / Function Calling）
  → 文本流 → 独立 Qwen-Audio-3.0-TTS-Flash → PCM → 同一 Room
                                      └→ 同一 PCM + 文本 → ForcedAligner → viseme
事件 → Event Router → Speak Policy → TurnCoordinator → 需要时交 Realtime 最终表达
复杂任务 → 按需 LangGraph / 工具 / 状态 → 结构化结果 → 协调发声
```

### 实时主链

- 普通聊天禁止走 LangGraph，不恢复串联的外置聊天 LLM，不新增另一套 ASR/情绪/意图模型；Realtime只输出文本，禁止内置语音与独立TTS双播。
- Web 文本输入保留，进入同一机器人会话；同一人声不能同时经 PCM 与旧 ASR 文本触发两次回答。
- 音频准入只负责已确认的格式、来源、开关、限流和背压；本地电平用于观测，不冒充有效语义打断裁决。
- `speech_started` 是候选起声，可请求 HOLD；无效轮恢复原采样位置，有效插话取消旧 TTS、嘴型和旧响应，并处理 Realtime 未播助手上下文。没有 response/item ID、删除确认或可信游标时如实标未知。
- Realtime 生成完成、TTS 完成、Room 发布、设备实际播完是不同状态。浏览器试听只报 `browser_test`，不替代实体 `speaker` 回执。

### 会话、人格与记忆

- Chat 绑定 Persona/revision，机器人、Chat、Persona与任务状态隔离；完整历史持久化，近期上下文有界，不用20轮窗口截断完整历史展示。
- Persona 只在 Session 建立、切换、revision/核心规则变化时更新，不每轮发送完整提示词。动态事实与SocialState有来源、版本和预算；传感器材料不提升为系统指令。
- Provider 原生推理窗口、本地近期缓存与重连首次注入预算分别配置。旧样例中的8轮/3000字符是历史基线，不宣称当前值最优或字符等于Token；实际值查 `config/runtime_defaults.toml` 和当前实现。
- 重连只恢复所属身份的有界完整历史；未播助手输出不冒充已说，已完成用户更正保留。迟到的旧 ASR、旧 response、旧工具不能抢占新轮。
- 有价值的偏好与经历才进入长期记忆，召回必须相关、限量且可解释；更正、遗忘按来源和版本防止迟到写入复活旧事实。前台检索有预算，后台抽取/embedding/持久化不拖慢普通首响。
- Ledger 保留用户输入、生成、发布、已播/未知与取消事实；必需Ledger和删除请求不与可丢弃Trace混为一谈。

### 事件、动作与复杂任务

- Event Router先校验所属robot/Room；Context Only只更新事实，不自动回答。Speak Policy决定值不值得说，TurnCoordinator决定现在能不能说，Realtime负责最终表达。
- 简单动作、表情、工具由Function Calling提出，本地校验允许集、参数、身份、幂等与取消再执行；模型要求执行不等于设备已执行。物理回执按协议留证。
- LangGraph仅按需执行多步骤/多Tool/Memory、暂停恢复和复杂事件，返回事实、状态与结果，不替代实时主脑；空闲主动规划仍由Runtime掌握现场、冷却和最终发声许可。
- 定时提醒、视觉事件、复杂任务结果不能绕过用户优先、回合归属或SpeakRequest协调。不扩大为自由自主Agent，不凭无声源证据识别旁人身份。

## 正式网页与 WEB-01～08

唯一前端是 `web/`，工作台和大屏共享React/TypeScript/Vite构建、后端与真实数据；Python提供 `web/dist/`，生产不依赖常驻Node开发服务器，不恢复独立临时HTML。

网页关闭不停止机器人Runtime。主操作、当前robot/Room/Chat、停止按钮及中文结果先于诊断JSON；完整历史、Persona、PCM、语音/记忆/动作/事件与分轮诊断沿用已有接线。Provider密钥不进浏览器，未知能力不伪装ready。

动效沿用GSAP + @gsap/react及锁文件精确版本；简单反馈用CSS，不并装第二套引擎。减少动效、卸载清理、中断、实时并发必须验；波形只能来自真实采样，不延迟请求或取消。

| 编号 | 必须核验的内容 |
| --- | --- |
| WEB-01 正式入口 | 构建后经统一启动打开、刷新工作台；无空白/资源缺失/未处理错误。留URL、构建版本、HTTP证据。 |

## 性能与统一实测待办

- 使用本地单调时钟测耗时，业务wall-clock单列；服务端与本机时钟不直接相减，缺少时点留null，记录来源和映射误差。
- 分开统计：PCM收帧/排队/上送、speech/有效轮、首文本、首可播段、TTS首PCM、Room首发布、设备起停播、对齐与音画偏差；检索/embedding、工具续推理、Graph、SQLite及合法等待单列。
- 同一typed trace驱动网页、Developer与JSON，不维护多套口径。Trace有界且累计丢失/写失败；Phase 9最近128轮与2秒进程采样不改为逐PCM观测。
- 每组报告样本数、P50/P95、失败/超时/丢弃/取消及缺失；普通聊天、工具、事件、复杂任务，单/双头、冷/暖Session分组，不只报均值或成功样本。
- 原本地P95工程目标仍仅为待实测参考：事件归一<5ms、音频Gate<10ms、必要SQLite读取<10ms、本地发声仲裁<5ms、非记忆动态Context<20ms、本地cancel<30ms；普通聊天Graph调用0次。排队、云端和设备延迟另列，不能靠删慢样本达标。
- 用户统一测试时，真实麦克风→扬声器按组至少100轮；连续运行、重连、TTS背压、写失败、插话/误打断恢复、跨Chat/Persona/Room隔离、记忆更正/遗忘、动作和视觉留证。
- 固定模型/参数、Persona revision、输入、历史/记忆、机器和网络；真实设备与声学阈值由既有确认或用户确定，不能跑完后移动门槛。V1/V2不同模型的结果不全部归因于架构，历史4个成功样本不是基线。
- 当前仍待真实人声、实体播放回执、AEC、ForcedAligner嘴型、模型多轮人格质量、浏览器与长时间运行统一确认。没有这些证据不签发整体验收PASS。

