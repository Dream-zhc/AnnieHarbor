# 工作台“内心”面板改版（2026-11-03）

用户反馈：发来右侧“内心”面板的截图，说 UI 太差劲、页面不好看。

```text
本次问题与范围：内心面板原来是十来行“标签：一长串文字”，心情、精力、今天的经历和调试信息挤在一起，看不出重点；面板标题还被通用规则压成灰色小字。只改前端展示，不改接口和数据。
目标与用户可见效果：先看到她此刻的心情（表情、心情名、原因、精力条、心情条，颜色跟着心情变），再看眼前是谁、对话进行到第几轮，然后是今天的经历时间线、她最近的回顾和待续话题；调试类信息收进底部“更多状态”，默认收起。
输入 → 处理 → 输出：GET /api/robots/{id}/inner-life（4 秒轮询，没变）→ innerLifeView 整理成展示字段 → InnerLifePanel 渲染。
改动文件：web/src/inner-life-state.ts、web/src/inner-life.tsx、web/src/styles.css、web/tests/inner-life.test.mjs、web/dist。
保留项：原有信息都还在（心里有话、交互动作、上一轮判断、会话同步、对话摘要、动作明细收进“更多状态”）；原有展示字段和测试不变；面板位置、默认展开、在语音状态面板之上不变。
不做事项：不改后端接口，不加新数据；不改语音状态面板的内容和布局。
结果：前端类型检查和 141 个单测通过，已重新构建 web/dist；刷新工作台页面生效，不用重启主脑。
```

## 1. 新布局（从上到下）

| 区块 | 内容 | 说明 |
| --- | --- | --- |
| 心情卡 | 表情 + 心情名 + 一句原因（带北京时间）；精力条（0–100%）；心情条（-1 难过到 +1 开心，圆点标位置，右边是数值） | 边框、底色光晕、表情圈和标题右侧徽标按心情换色：开心绿、感动粉、委屈紫、担心琥珀、发闷灰、吓一跳橙、平静天蓝 |
| 两个小标签 | 眼前（认出的人，没认出就写“没认出”）、对话（进行中 · N 轮 / 没有） | 鼠标停留显示原来的完整说明 |
| 今天的经历 | 时间线：时间 · 图标 · 事情，标题右侧写件数 | 超过高度在卡片内滚动 |
| 她最近 / 待续话题 | 每晚反思的一句话（引用样式，标日期）、对TA的印象（认出人时才有）、待续话题列表 | 没有时显示灰色提示 |
| 更多状态（默认收起） | 心里有话、交互动作、上一轮判断、会话同步、对话摘要、最近动作明细 | 原来的调试信息一条不少 |

## 2. 顺手统一的地方

- 右侧三块面板（内心、语音状态、网页麦克风/试听）的标题原本被通用的 `.inspector-panel > summary span` 规则压成 11px 灰色细字，现在恢复成 12px 粗体主色，右侧徽标恢复原定的 10px 天蓝色；内心面板的徽标跟心情换色。
- 内心面板的卡片沿用语音状态面板子卡片的底色、边框和圆角；深色和浅色主题都有对应颜色。

## 3. 验证

- `web/tests/inner-life.test.mjs` 新增“心情卡的表情、进度条和短原因”测试：开心对应 😊、精力 62%、心情 +0.33 对应条上 67% 的位置、原因带 10:20；没有原因时不显示原因，超出范围的心情值按 -1 处理；未启用时显示“未启用”和开关说明。
- 内置浏览器这次连不上，没法在真页面截图。改用本机离线渲染：把组件按样例数据（张三、李四为占位名）服务端渲染成静态页面，套上真实样式表，用 macOS 快速查看生成预览图；深色、浅色主题和“更多状态”展开后的样子都看过。
